ทำไมต้องมีWhy

เปิด Wi-Fi ให้ลูกค้า = มีหน้าที่ตามกฎหมายFree Wi-Fi comes with legal duties

ร้านที่ให้ลูกค้าใช้อินเทอร์เน็ตต้องเก็บข้อมูลจราจรทางคอมพิวเตอร์และระบุตัวผู้ใช้ได้ แต่เราเตอร์ทั่วไปทำไม่ได้ และระบบสำเร็จรูปส่วนใหญ่ต้องใช้ช่างที่ถนัด Linux Cafe-WiFi OS ทำให้การติดตั้งเหลือแค่ flash การ์ดกับกดตามหน้าเว็บ A shop that offers internet access has to keep computer traffic data and be able to identify its users. Ordinary routers can't do this, and most turnkey systems need a Linux-savvy technician. Cafe-WiFi OS turns installation into flashing a card and following a web wizard.

พ.ร.บ.คอมพิวเตอร์ฯ มาตรา 26 — ผู้ให้บริการต้องเก็บรักษาข้อมูลจราจรทางคอมพิวเตอร์ไว้ไม่น้อยกว่า 90 วัน และต้องเก็บข้อมูลของผู้ใช้บริการเท่าที่จำเป็นเพื่อให้สามารถระบุตัวผู้ใช้บริการได้

Cafe-WiFi OS เก็บ log การเชื่อมต่อและ DNS ตามจำนวนวันที่ตั้ง (≥ 90 วัน) ตรวจความครบถ้วนด้วย hash และส่งออกเป็นหลักฐานได้เมื่อมีหมายศาล Computer Crime Act B.E. 2550, Section 26 — service providers must retain computer traffic data for at least 90 days and keep the user information needed to identify each user.

Cafe-WiFi OS keeps connection and DNS logs for the configured period (≥ 90 days), checks their integrity with hashes, and exports them as evidence when a court order arrives.

แก้ปัญหาTroubleshooting

เปิด cafewifi.local ไม่ได้cafewifi.local won't open

มือถือ Android บางรุ่นไม่รองรับ mDNS — ดู IP ของ Pi ในหน้าเราเตอร์แล้วเปิดด้วย IP แทน Some Android phones don't support mDNS — find the Pi's IP on the router page and open that instead.

SD card เสีย ต้องเปลี่ยนการ์ดThe SD card died

flash การ์ดใหม่ → เสียบ USB CAFEBACKUP ของเครื่องเดิม → wizard ขั้น ② กด “กู้คืนจากเครื่องเดิม” → เลือกไฟล์ .cwkey + ใส่รหัสผ่าน → ข้อมูลลูกค้า, log และบัญชีพนักงานกลับมาครบ (ระบบตรวจก่อนว่ากุญแจถอดข้อมูลในไฟล์สำรองได้จริง) → ทำขั้น ③–⑤ ต่อ Flash a new card → plug in the old CAFEBACKUP USB → wizard step ② “Restore from old device” → choose the .cwkey file + password → customers, logs and staff accounts all come back (the key is verified against the backup first) → continue with ③–⑤.

ตรวจ “DHCP ยังเปิดอยู่” ไม่ผ่าน ทั้งที่ปิดแล้ว“DHCP still on” although it's off

มีอุปกรณ์อื่นจ่าย DHCP อยู่ เช่น Access Point ที่ตั้งเป็นโหมด router — ปิด DHCP บนอุปกรณ์นั้นด้วย Another device is serving DHCP, e.g. an access point in router mode — turn DHCP off there too.

ความปลอดภัยSecurity

ข้อมูลลูกค้าต้องปลอดภัย แม้ image เดียวกันใช้หลายร้านCustomer data stays safe, even with one image in many shops

ไม่มีความลับใน imageNo secrets in the image

กุญแจ, pepper, session key, รหัสฐานข้อมูล, ใบรับรอง TLS, SSH host key สร้างใหม่บน Pi แต่ละเครื่องตอนบูตแรก Keys, pepper, session key, DB password, TLS certificate and SSH host keys are generated on each Pi at first boot.

เลขบัตรเข้ารหัสEncrypted IDs

เลขบัตรประชาชนเก็บแบบ AES-256-GCM + hash แยกไว้ค้นหา · รหัสผ่านพนักงานใช้ argon2id National IDs stored with AES-256-GCM plus a separate lookup hash · staff passwords use argon2id.

ไม่มีรหัสผ่านเข้าเครื่องNo password logins

ช่างเข้าได้ทาง SSH key เท่านั้น · wizard ต้องมี setup code (ผิด 5 ครั้งล็อก) และปิดตัวเองถาวรเมื่อตั้งเสร็จ Technicians log in with SSH keys only · the wizard needs the setup code (locks after 5 tries) and closes itself for good.

สำรองและกู้คืนผ่านเว็บBackup & web restore

ไฟล์ .cwkey ล็อกด้วย scrypt + AES-256-GCM · การ์ดเสียก็ flash ใหม่แล้วกู้คืนจากหน้าเว็บได้ครบ .cwkey locked with scrypt + AES-256-GCM · if the card dies, flash a new one and restore everything from the web.
