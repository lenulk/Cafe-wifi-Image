# Cafe-WiFi OS

**Wi-Fi ร้านกาแฟที่เก็บ log ถูกกฎหมาย — flash การ์ด เสียบสาย LAN ตั้งค่าผ่านเว็บ ไม่ต้องใช้ command line**

🌐 **เว็บไซต์: <https://lenulk.github.io/Cafe-wifi-Image/>** (ไทย / English)

ระบบสำเร็จรูปบน Raspberry Pi 4B สำหรับร้านที่เปิด Wi-Fi ให้ลูกค้า ลูกค้าลงทะเบียนเลขประจำตัวประชาชนที่หน้า
captive portal → พนักงานกดอนุมัติ → ออกเน็ตได้ ระบบเก็บข้อมูลจราจรทางคอมพิวเตอร์ตาม
**พ.ร.บ.คอมพิวเตอร์ฯ มาตรา 26** ให้อัตโนมัติ และส่งออกเป็นหลักฐานได้เมื่อมีหมายศาล

## ทำอะไรได้บ้าง

| สำหรับ | |
|---|---|
| **ลูกค้า** | ต่อ Wi-Fi ร้าน → หน้าลงทะเบียนเด้งขึ้นเอง → กรอกเลขบัตร + ยินยอม → รอพนักงานอนุมัติ |
| **พนักงาน** | หน้าแอดมิน `https://admin.cafe.wifi` จากมือถือ/คอมในร้าน: อนุมัติ/ปฏิเสธ, ต่อเวลา, ปิดสิทธิ์ (มีผลทันที), ดูเครื่องที่ใช้อยู่ |
| **เจ้าของร้าน** | log การเชื่อมต่อ + DNS เก็บตามจำนวนวันที่ตั้ง (≥ 90 วัน), ตรวจความครบถ้วนด้วย hash, ส่งออกหลักฐานตามหมายศาล, ลบข้อมูลเก่าอัตโนมัติ |
| **ช่างติดตั้ง** | flash การ์ด → wizard บนเว็บ 5 ขั้น — ระบบตรวจให้เองว่าเราเตอร์ปิด DHCP/IPv6 แล้วจริง ก่อนยอมเปิดใช้งาน |

ใช้กับเราเตอร์ของร้านที่มีอยู่แล้ว — Pi ต่อสาย LAN **เส้นเดียว** ไม่ต้องเปลี่ยนอุปกรณ์เครือข่าย

## ดาวน์โหลด

**[Release ล่าสุด](https://github.com/lenulk/Cafe-wifi-Image/releases/latest)** — ไฟล์ `cafe-wifi-<รุ่น>.img.xz` (~650 MB) พร้อม SHA-256

| | |
|---|---|
| ฮาร์ดแวร์ | Raspberry Pi 4B + SD card ≥ 8 GB + สาย LAN 1 เส้นไปเราเตอร์ร้าน + (แนะนำ) USB สำรองข้อมูล |
| ระบบฐาน | Raspberry Pi OS Lite 64-bit (Debian 13 trixie) |
| คอมสำหรับเตรียมการ์ด | Windows + [Raspberry Pi Imager](https://www.raspberrypi.com/software/) |

## ติดตั้ง 5 ขั้น (~30 นาทีหน้างาน)

1. **เขียนการ์ด** — Raspberry Pi Imager → Device: Raspberry Pi 4 → OS: *Use custom* → เลือกไฟล์ `.img.xz`
   (ถามเรื่อง OS customisation ให้ตอบ **No**)
2. **เตรียมการ์ด** — รัน [`image/prepare-sd.ps1`](image/prepare-sd.ps1) ใน PowerShell ใส่ชื่อร้าน → **จด setup code**
3. **บูต** — ต่อสาย LAN จากเราเตอร์ร้าน (DHCP ของเราเตอร์**ยังเปิด**ในขั้นนี้) แล้วเสียบไฟ รอ LED กะพริบแบบ heartbeat (~1 นาที)
4. **ตั้งค่าผ่านเว็บ** — มือถือที่ต่อ Wi-Fi ร้าน เปิด **`http://cafewifi.local`**
   ① setup code ② สร้างแอดมิน ③ เครือข่าย (ระบบเสนอให้) ④ **ปิด DHCP และ IPv6 ที่เราเตอร์** แล้วกด "ตรวจสอบ" ⑤ บันทึก
5. **ส่งมอบ** — ดาวน์โหลด**ไฟล์สำรองกุญแจ** เก็บนอกเครื่อง, เสียบ USB สำรองข้อมูล, ติดตั้งใบรับรองของร้านบนเครื่องพนักงาน

คู่มือเต็มพร้อมตารางแก้ปัญหา: [`docs/install-from-image.md`](docs/install-from-image.md)

| ③ เครือข่าย — ระบบเสนอค่าให้ | ④ ตรวจเราเตอร์ — DHCP ยังเปิด | ④ ปิดแล้ว ✅ บันทึกได้ |

## ความปลอดภัย

- **ไม่มีความลับใน image** — กุญแจเข้ารหัสเลขบัตร, pepper, session key, รหัสฐานข้อมูล, ใบรับรอง TLS, SSH host key
  สร้างใหม่บน Pi แต่ละเครื่องตอนบูตครั้งแรก (flash image เดียวกันกี่เครื่อง กุญแจก็ไม่ซ้ำกัน)
- เลขบัตรประชาชนเก็บแบบ**เข้ารหัส** (AES-256-GCM) + hash แยกไว้ค้นหา · รหัสผ่านพนักงาน argon2id
- **ไม่มีบัญชีที่ใช้รหัสผ่านเข้าเครื่อง** — ช่างเข้าได้ทาง SSH key เท่านั้น
- wizard เปิดได้เฉพาะคนที่มี setup code (ผิด 5 ครั้งล็อก 15 นาที) และปิดตัวเองถาวรเมื่อตั้งเสร็จ
- **สำรองกุญแจ** — ไฟล์ `.cwkey` ล็อกด้วยรหัสผ่านที่ตั้งเอง (scrypt + AES-256-GCM) · การ์ดเสีย: flash ใหม่แล้ว
  **กู้คืนผ่านหน้าเว็บ** (ไฟล์ `.cwkey` + USB สำรองข้อมูล) ข้อมูลลูกค้า, log และบัญชีพนักงานกลับมาครบ
- **Factory reset** — ตั้งเครือข่ายผิด/เปลี่ยนเราเตอร์: `prepare-sd.ps1 -FactoryReset` แล้วตั้งใหม่ผ่าน wizard ไม่ลบข้อมูล
- นโยบายความเป็นส่วนตัวสำหรับติดหน้าร้าน: [`docs/privacy-policy-th.md`](docs/privacy-policy-th.md)

## ทดสอบบน Raspberry Pi 4B จริง

| ทดสอบ | ผล |
|---|---|
| ไม่มีความลับในไฟล์ image (ตรวจกับไฟล์ .img จริง) | ✅ |
| flash image เดิมซ้ำ → ความลับใหม่ทุกตัว (8/8) | ✅ |
| ติดตั้งได้โดยไม่มีอินเทอร์เน็ต · ไฟดับกลางบูตแรกแล้วทำต่อได้ | ✅ |
| setup code ผิด 5 ครั้ง → ล็อก | ✅ |
| ตรวจเราเตอร์: จับ DHCP และ IPv6 RA ที่ยังเปิดได้ทั้งคู่ | ✅ |
| ทดสอบทั้งระบบ (ลงทะเบียน → อนุมัติ → ออกเน็ต → ต่อเวลา → ปิดสิทธิ์ → log → ส่งออกหลักฐาน) | ✅ 49/49 |
| ปิดสิทธิ์ลูกค้า → เน็ตถูกตัด | ✅ ~7–8 วินาที |
| การ์ดเสีย → flash ใหม่ → **กู้คืนผ่านหน้าเว็บ** (.cwkey + USB) → ข้อมูลลูกค้า/log/บัญชีพนักงานกลับมาครบ | ✅ |
| factory reset → กลับเข้า wizard โดยข้อมูลไม่หาย | ✅ ~85 วินาที |
| มือถือ Android ที่ยังไม่ได้อนุมัติ + ติดตั้งใบรับรองร้าน → เปิดหน้าแอดมินได้ไม่มีหน้าเตือน | ✅ |
| เวลาติดตั้ง ตั้งแต่เสียบไฟจนใช้งานได้ | ~6 นาที |

## ข้อจำกัดที่รู้แล้ว

- ต้องใช้เราเตอร์ที่**ปิด DHCP และ IPv6 ฝั่ง LAN ได้** (ระบบตรวจให้ก่อนเปิดใช้)
- ใบรับรองหน้าแอดมินเป็นของร้านเอง (ไม่ใช่ CA สาธารณะ) — เครื่องพนักงานติดตั้งใบรับรองครั้งเดียว
  (ลิงก์ในหน้าสถานะระบบ) แล้วเปิดหน้าแอดมินได้โดยไม่มีหน้าเตือน ทดสอบแล้วบน Android 10
